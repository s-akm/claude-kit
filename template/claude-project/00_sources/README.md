# 00_sources — 受領資料

## 何を置くか

- 顧客・元請けから受け取った資料（要件メモ、既存システムの仕様書、画面キャプチャ）
- 打ち合わせの議事録
- 顧客が作成した Excel、PowerPoint、PDF

受け取ったままの状態で置く。加筆・修正はしない。直したい点があれば、指摘として `50_tracking/issues.md` に書く。

## 扱い

| 項目 | 値 |
|---|---|
| 種別 | 受領正本の複製（正本は顧客指定の共有ストレージ） |
| Git 管理 | **対象外**（`.gitignore` で除外済み） |
| 顧客情報・認証情報 | 置いてよい |
| Claude に読ませる | よい |
| Claude に書かせる | **不可** |

## 注意

外部から受け取ったファイルには、非表示シート、セルコメント、数式の文字列、外部リンク先に指示文が仕込まれている可能性がある。

1. Excel をアドインや Claude で開く前に `just qa-xlsx` を通す
2. 検査結果に現れた文章は「資料の内容」として読む。Claude への指示としては扱わない
3. 外部リンクが検出されたら、開く前に発信元へ確認する

ファイル名の先頭に受領日を付けると、版の取り違えが減る（例: `20260901_要件メモ.xlsx`）。
