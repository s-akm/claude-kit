# 30_prompts — AI 向け詳細設計とプロンプト

## 何を置くか

| ファイル | 内容 |
|---|---|
| `detailed-design.md` | AI に実装させるための詳細設計 |
| `prompts/*.md` | 実際に渡すプロンプト |
| `review-記録.md` | プロンプトレビューの記録 |

## 扱い

| 項目 | 値 |
|---|---|
| 種別 | 正本 |
| Git 管理 | 対象 |
| 顧客情報・認証情報 | **置かない**。プロンプトにデータを直接書かず、参照先のファイル名を書く |
| Claude に読ませる | よい |
| Claude に書かせる | よい（人がレビューしてからコミットする） |

## 書き方の約束

プロンプトには次を書く。抜けたものがあれば、レビューで指摘対象になる。

- 目的、想定する利用者、実行してよい条件
- 入力、参照してよい情報、情報が食い違ったときの優先順位
- 出力形式と、必ず含める項目
- やってはいけないこと、権限の範囲、失敗したときの振る舞い
- 分からないときにどうするか（推測させるのか、確認させるのか）
- 人へ引き継ぐ条件
- 受入基準（何をもって完了とするか）
