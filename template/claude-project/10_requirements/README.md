# 10_requirements — 要件

## 何を置くか

| ファイル | 内容 |
|---|---|
| `functional.md` | 機能要件 |
| `non-functional.md` | 非機能要件 |
| `glossary.md` | 用語集 |
| `decisions.md` | 決定事項一覧 |
| `open-items.md` | 未決事項一覧 |

要件の一覧を Excel で作る場合も、正本の判断はここの Markdown に置き、Excel は提出用の表現として `80_deliverables/` に置く。二重管理になるため、両方を正本にしない。

## 扱い

| 項目 | 値 |
|---|---|
| 種別 | 正本 |
| Git 管理 | 対象 |
| 顧客情報・認証情報 | **置かない**（固有名詞は `glossary.md` で一般語に対応づける） |
| Claude に読ませる | よい |
| Claude に書かせる | よい（人がレビューしてからコミットする） |

## 書き方の約束

- 要件 1 件につき ID を 1 つ。ID の付け方は `CLAUDE.md` の採番規約に従う
- 決まったことは `decisions.md`、決まっていないことは `open-items.md`。この 2 つを混ぜない
- 未決には「誰が」「いつまでに」「何を決めるか」を書く。3 つのどれかが空なら、それも未決として扱う
- 「〜を検討する」で終わる行は要件ではない。未決事項へ移す
