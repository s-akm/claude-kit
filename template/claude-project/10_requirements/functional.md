## この表の読み方

| 列 | 書くこと |
|---|---|
| ID | `FR-` ＋ 3 桁。欠番は埋めない |
| 分類 | 画面／バッチ／連携／通知 のいずれか |
| 要件 | 「誰が」「何を」「どうできる」を 1 文で書く。体言止めにしない |
| 根拠 | 出典。議事録の日付、または受領資料のファイル名と箇所 |
| 受入条件 | 満たしたと判断できる条件。「正しく動くこと」は条件ではない |
| 状態 | 確定／調整中／未決（`OI-nn`） |

## 書くときの注意

- 「〜を検討する」「〜を考慮する」で終わる行は要件ではない。`open-items.md` へ移す
- 非機能の話（速度、可用性、監視）はこの表に混ぜない。`non-functional.md` に書く
- 1 行に 2 つの要件を書かない。「かつ」「および」でつないだら、分けられないか疑う
