# 用語集

同じものを 2 通りに呼ばない。資料全体でここの「使う語」に統一する。

| 使う語 | 使わない語 | 意味 | 備考 |
|---|---|---|---|
| 記事 | コンテンツ、ページ | 編集者が作成し公開する単位 | 画面上の表記も「記事」 |
| 公開 | リリース、反映 | 記事を閲覧できる状態にすること | |
| 発注元 | （顧客名） | | 資料には一般語で書く |
| 元請け | （社名） | | 同上 |

## 追加するとき

- レビューで「この語は何を指すのか」と聞かれたら、答えるだけでなくここに足す
- 顧客の固有名詞は「使わない語」の側に置き、資料本文では一般語を使う
- 略語は初出時に正式名称を書く。ここには両方載せる
