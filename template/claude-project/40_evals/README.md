# 40_evals — プロンプトの評価

## 何を置くか

| パス | 内容 | Git |
|---|---|---|
| `cases/` | 評価ケース。入力と期待する結果 | 対象 |
| `runs/` | 実行結果 | **対象外** |

## 扱い

| 項目 | 値 |
|---|---|
| 種別 | ケースは正本、結果は生成物 |
| Git 管理 | `cases/` のみ対象 |
| 顧客情報・認証情報 | **置かない**。ケースの入力は匿名の作り物にする |
| Claude に読ませる | よい |
| Claude に書かせる | よい |

## 書き方の約束

ケースは 4 種類そろえる。1 種類でも欠けていれば、そのプロンプトはまだ評価できていない。

- 正常系
- 異常系（入力が足りない、形式が違う）
- 境界（上限、下限、空、最大長）
- 敵対的入力（プロンプトインジェクションを想定した文字列）
