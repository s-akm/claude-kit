# 50_tracking — 課題と進捗

## 何を置くか

| ファイル | 内容 |
|---|---|
| `issues.md` | 課題一覧 |
| `traceability.md` | 要件 → 設計 → 試験の対応表 |
| `progress-snapshot.md` | 進捗のスナップショット（日付つき） |

## 扱い

| 項目 | 値 |
|---|---|
| 種別 | 作業コピー |
| Git 管理 | 対象 |
| 顧客情報・認証情報 | **置かない**。担当者は実名ではなく役割で書く（「発注元 情シス」「元請け PM」） |
| Claude に読ませる | よい |
| Claude に書かせる | よい |

## 書き方の約束

- 変動する情報はここに置く。`CLAUDE.md` には書かない
- `progress-snapshot.md` は上書きせず、日付の見出しを足していく。いつ何が変わったかを後から追えるようにする
- トレーサビリティ表で対応先が空の行は、そのまま課題として `issues.md` に出す
