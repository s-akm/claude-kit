# 80_deliverables — 提出物

## 何を置くか

顧客・元請けへ提出する Excel、PowerPoint、Word、PDF。提出したものそのもの。

ファイル名に提出日を入れる（例: `要件定義書_20260901.xlsx`）。提出済みのファイルは上書きせず、新しい日付で足す。

## 扱い

| 項目 | 値 |
|---|---|
| 種別 | 提出正本 |
| Git 管理 | **対象外**（顧客情報を含み、バイナリのため差分も追えない） |
| 顧客情報・認証情報 | 顧客情報は入る。認証情報は入れない |
| Claude に読ませる | よい |
| Claude に書かせる | **不可**。提出物を機械が上書きしない |

## 注意

Claude に資料を作らせる場合は、作業用の複製を別名で作らせ、内容を確認してからここへ置く。

提出前に `just qa <このプロジェクト>` を通し、`90_qa/` の結果を確認する。
