# 導入手順

## A. Cowork / Claude デスクトップアプリへの導入

1. `jp-client-deliverables.plugin` をチャットへ添付
2. プレビューカードの内容を確認し、インストールを実行
3. スキル一覧に 9 件が追加

Excel・PowerPoint・Word のアドインからも、同じスキルを `/` で呼び出し可能。

## B. Claude Code への導入（プラグインとして）

```bash
unzip jp-client-deliverables.plugin -d ~/.claude/plugins/jp-client-deliverables
```

`~/.claude/plugins/jp-client-deliverables/.claude-plugin/plugin.json` の存在が読み込みの条件。

claude-kit をリポジトリごと持っている場合は、シンボリックリンクでも可。

```bash
ln -s ~/workspace/claude-kit/plugin ~/.claude/plugins/jp-client-deliverables
```

## C. スキル単体での配置

プラグインの仕組みを使わず、スキルのみの配置も可能。

```bash
unzip jp-client-deliverables.plugin -d /tmp/jpkit
cp -r /tmp/jpkit/skills/* ~/.claude/skills/
```

この場合、スキル間の相互参照（`japanese-business-writing/references/...` のような記述）は
相対パスではなくスキル名で解決。Claude はスキル名で探索するため、動作は同一。

## D. リポジトリ運用

このディレクトリは claude-kit の `plugin/` に相当。プロジェクトごとに指摘を追加していく前提のため、
配布物の配置ではなく、リポジトリの clone を推奨。

```bash
cd ~/workspace
git clone https://github.com/s-akm/claude-kit.git
```

プロジェクトで新しい指摘を受けた際の反映手順。

1. 該当スキルの `references/` に行を追加
2. 機械走査で拾える指摘は `japanese-business-writing/scripts/patterns.json` にも追加
3. `CHANGELOG.md` に日付と内容を 1 行記載
4. コミット

### 再パッケージ

claude-kit のリポジトリがある場合。

```bash
cd ~/workspace/claude-kit
bin/build-plugin
```

バージョンとスキル名の対応、CHANGELOG への現バージョンの見出しの有無を検証後、`dist/` へ出力。

リポジトリを持たず、この `plugin/` ディレクトリのみを扱う場合。

```bash
zip -r /tmp/jp-client-deliverables.plugin . \
  -x "*.DS_Store" -x "*__pycache__/*" -x "*.plugin"
```

## E. 更新（既にインストール済みの場合）

Claude デスクトップアプリと claude.ai は、`.plugin` の再アップロードで差し替え。
リポジトリを修正しただけでは、Claude が読むスキルは旧版のまま。

1. `bin/build-plugin` で `dist/jp-client-deliverables.plugin` を再生成
2. 新しいチャットを開き、`.plugin` をドラッグして添付
3. プレビューカードで名前とバージョンを確認し、インストールを実行。同名のプラグインは上書き
4. 設定 → プラグイン（または「カスタマイズ」）で `jp-client-deliverables` のバージョンが新しいことを確認
5. 開いていたチャットは旧版を読み込んでいる場合があるため、新しいチャットで `/` からスキルを呼び出して確認

Claude Code でシンボリックリンク運用（B）の場合は、リポジトリの修正がそのまま反映。再インストール不要。

## スクリプトの依存関係

| スクリプト | 依存 |
|---|---|
| `japanese-business-writing/scripts/scan_expressions.py` | 標準ライブラリのみ |
| `requirements-xlsx/scripts/xlsx_open_items.py` | 標準ライブラリのみ |
| `requirements-xlsx/scripts/xlsx_qa.py` | openpyxl |
| `pptx-house-style/scripts/pptx_qa.py` / `pptx_audit.py` / `pptx_measure.py` / `deckkit.py` | python-pptx、lxml |
| `pptx-house-style/scripts/pdf_qa.py` | pypdf、qpdf（外部コマンド） |
| `pptx-house-style/scripts/contact_sheet.py` | Pillow、poppler（`pdftoppm`） |

claude-kit のリポジトリがある場合、`uv.lock` でバージョンを固定済み。個別のインストールは不要。

```bash
cd ~/workspace/claude-kit
uv run python plugin/skills/requirements-xlsx/scripts/xlsx_qa.py 対象.xlsx --out-dir /tmp/qa
```

単体で使う場合のインストール。

```bash
pip3 install openpyxl python-pptx pypdf lxml Pillow
brew install poppler qpdf
```

`contact_sheet.py` の入力は PDF。pptx からの変換は PowerPoint の書き出しを使う。
LibreOffice でも変換できるが、日本語フォントが macOS と異なり文字切れの判定が不一致。

## 動作確認

```bash
python3 skills/japanese-business-writing/scripts/scan_expressions.py README.md
python3 skills/requirements-xlsx/scripts/xlsx_open_items.py 対象.xlsx
```

前者は README 内の記号などを検出して件数を返却。後者は未決セルとコメントを一覧化。
どちらもエラーなく終了すれば導入完了。
