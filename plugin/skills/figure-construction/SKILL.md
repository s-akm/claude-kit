# 図を1枚組み立てる

実企業スライド40枚を解剖して数えた結果を、そのまま実行できる順序にしたもの。
根拠の数値はすべて実測。括弧の中は40枚のうち何枚がそうしていたか。

## 先に、失敗の形を知る

AIが図を作ると、ほぼ必ずこうなる。

> 白地に、同じ大きさの白い箱を4つ等間隔に並べ、それぞれに6文字の見出しと1行の説明を入れ、上に丸いアイコンを乗せる

要素数16、文字数60、入れ子1層、起点なし、運動なし、終点なし。
40枚の中央値は要素数47、文字数375、入れ子3層。**2.9倍と6.3倍の差**がある。
「情報量が少ない」「フラット」「ダサい」は、この差のことを指している。

とくに次の3つは、40枚が例外なく持っていて、AIの図には無い。

| | 40枚 | AIの図 |
|---|---|---|
| 入れ子が2層以上 | 40/40（3層以上が34枚） | 1層 |
| 1行の中で太さ・色・大きさを変える | 40/40 | なし |
| 起点・運動・終点が3つとも揃う | 34/40 | なし |

そして **箱の上に飾りの丸いアイコンを乗せた例は、40枚中0枚**。
アイコンを使う9枚は全部、線画のまま置くか、番号・分類を担うバッジにしている。
丸で囲うのは、その丸が「工程の1点」「収斂点」を意味するときだけ。

## 組み立ての順序

### 1. 紙の役割を先に決める（40/40）

- 見出しは1行で終えない。**上段に小さくカテゴリか章番号、下段に大きく主題**の2段（27/40）
- 見出しと図の間に、全幅の細い横罫か薄い地の帯を1本入れて切る（22/40）
- リード文を1〜4行（28/40）。**主張の核だけ太字か色付き**にする（21/28）
- 右上にロゴ、右下にページ番号、左下にコピーライト。ここは最後まで触らない

### 2. 図領域に地を敷く（34/40）

図領域の全体に薄い地を1枚敷く。白地のまま図を置いていたのは6枚だけ。
**これだけで入れ子が1層増える**（面→箱）。

地の上に、骨格を1つ決める。3〜4列（16枚）、3〜4段（12枚）、閉じた環（7枚）、放射（4枚）。
骨格の各区画に、濃色の角丸帯＋白抜き文字で**区画の名前を先に宣言する**。

### 3. 起点を置く（37/40）

左端（21枚）、下端（5枚）、中心（4枚）のいずれかに、起点の箱を置く。
起点は「投入するもの」「今いる場所」「外から入ってくる側」のどれか。
**起点は他の箱と、形か色か枠線を変える。**

並列の項目しか無いときでも、左端に「読み方の宣言」（軸の名前、対象、前提）を1つ置けば起点になる。

### 4. 運動を1本通す（38/40）

起点から終点へ、運動を1つだけ選ぶ。左→右／上から下／下から上／円環／中心から放射。
**2つの運動を混ぜるときは必ず入れ子にする**（上の左→右のフローと、下の縦の支えを直交させる）。

運動の担い手は矢印だけではない。**矢羽の連鎖（11枚）、面の傾き（2枚）、段の幅の変化（6枚）、色の濃淡の順序（8枚）**でも運動は作れる。
色の濃淡を左から右へ4段階にするだけでも運動になる。

運動の途中に中継点を置く。起点と終点を直結させない。

### 5. 終点を置く（35/40）

右端（19枚）、上端（4枚）、最下段（5枚）のいずれかに終点の箱を置く。
**終点は形を他と変える。** 円にする、破線枠にする、地を塗って白抜きにする。
円環のときは終点を起点に戻し、**戻りの矢印を他より太くする**。

### 6. 入れ子を2層目・3層目まで掘る（34/40が3層以上）

区画の中に箱を置く。これが2層目。箱の中をさらに割る。割り方は3通りしかない。

| 割り方 | 枚数 | 中身 |
|---|---|---|
| 見出し行＋説明行 | 26 | 見出し（太・中・色付き）＋説明（細・小・黒） |
| 中分類の帯＋その下の小箱グリッド | 8 | 帯1本＋2×2の白箱4つ |
| 箱の中の箇条書き | 10 | 3〜4行 |

**3層目を作る合図は「帯」。** 箱の中に細い横罫を1本置くと、その下が新しい階層になる。

箱の中の行数は、中央値2行。1行20%／2行32%／3行22%／4行20%／5行以上7%。
箱の中の文字数は中央値30文字。**6文字では足りない。**

### 7. 1行の中に階層を作る（40/40）

**1行の中で、太さ・色・大きさのうち最低2つを変える。** 40枚すべてがやっていた。

- 名詞句だけ太く、述語は素のまま：「**研修・訓練体制**の充実」「**新技術**の活用」
- 主張が文全体にあるときだけ、述語まで含めて強調する
- 1行の中の同格の語のうち、1語だけ色を変える
- 区切り記号は `｜`、全角コロン、全角括弧の3種だけ

**数値を出すときは必ず「小ラベル＋特大数値＋小単位」の3段**（14/14）。
数値を本文と同じ大きさで書いたスライドは1枚もない。
数値と単位の字高比は中央値1.64。**中央揃えではなく下端（ベースライン）揃え。**

### 8. 図の外に、図が説明できないものを出す（40/40）

- **凡例**を下端か上端に（6枚）
- **軸の名前**を左端と上端に、縦書きか横書きで（サンリオ、タイミー、True Data）
- **現在地**を打つ（赤い縦点線＋NOWバッジ、3タグのうち該当だけ濃色）
- **注記**を左下か右下に極小で（10枚）。図の中で書ききれない条件は全部ここへ
- **締めの一文**を下端に（H.I.S.＝紺の大きな一文、ジーニー＝赤い帯）

### 9. 離れた要素を、線を引かずに結ぶ（12/40）

**番号を両方に振る。** 図の中の丸数字と、右のリストの番号を対応させる。
**色を両方に合わせる。** 図の色と、右パネルのバッジの色を一致させる。
線を引かずに済むぶん、図が汚れない。

### 10. 最後に色を絞る

図の中の有彩色を3値以内に（26/40）。役割を固定する。
**同じ大きさの箱を並べるときは、地の色を変えて意味を分ける。**

## 長方形を、意味のある形に置き換える

| 今こう書いている | 置き換える形 |
|---|---|
| 工程・フェーズの箱を等間隔で並べている | **矢羽**。切り込み＝高さの半分（45°）、隙間＝高さの6%。期間の長さは幅で表す |
| 一番下に「基盤」の長方形を敷いている | **基壇**。上の層より片側4〜5%広く、色は上より薄く。2段にするとさらに効く |
| 「目的」の箱を一番上に置いている | **屋根**（五角形か三角）。高さ＝幅の10%、軒の出＝幅の3% |
| 「重点施策1／2／3」を縦長の長方形で並べている | **柱**。柱頭幅＝柱身幅の1.12倍、柱頭高さ＝柱全高の8%。中に白い小箱を3段（箱幅＝柱身幅の87%） |
| 選択肢・成長段階を同じ高さの箱で横に並べている | **階段の立体**。段板は平行四辺形、厚み＝幅の13%、斜辺40°、rise:run＝1:7 |
| 段階を色違いの長方形で縦に積んでいる（数が減る話） | **ファネル**。1つの三角をクリップして切る。幅の減り方は等差 |
| 階層を縦に積んでいる（上ほど価値が高い話） | **ピラミッド**。段の高さを等分すれば幅は自動で 1/n, 2/n… |
| 4つの箱を四角く並べて矢印4本で回している | **円環**。太さ＝外径の6%、節点の円＝リング太さの3倍 |
| 箱の間に細い矢印を引いている（変換・移動） | **太い矢印**。矢じり高さ＝軸の1.35倍、矢じり長＝全長の30%。中に動詞を入れる |
| 補足を本文と同じ枠付きの箱に入れている | **吹き出し**。角丸＝短辺の27%、しっぽ＝本体高さの35% |
| 「分類名」と「その中身」を2箱＋線で書いている | **入れ子の箱**。内箱は中央でなく片側へ寄せ、余白＝外箱幅の2% |
| 「AとBが連動する」を2箱＋双方向矢印で書いている | **かみ合う歯車2個**。内円＝外径の62%、歯の山と谷を実際に噛ませる |
| 「表に出ている数字」と「その裏」を上下2箱で書いている | **氷山**。水面上:水面下＝1:4、左右非対称、水面に細い横線1本 |
| 「入力→結論→効果」を3箱で書いている | **蝶ネクタイ**。中央の最も細い部分に結論を置く |
| 縦の箱の間に「↓」を打っている | **カードと同色の下向き三角**（幅＝カード幅の1/6、高さ＝幅の0.5） |
| 「当社の技術が事業を支えている」を上下関係で書いている | **樹**（根＝技術、幹＝会社、枝＝事業） |
| 成長トレンドを矢印1本で表している | **面グラフを図の地に敷く**。面が伸びる方向が成長の向きになる |

**立体は等角投影ではない。** 60枚に本物の等角投影は1例もなく、平行四辺形と台形だけで作られている。
**面ごとの明度差は最大17%、影は0件。**

## アイコンの扱い

**装飾として置かない。** 箱の上に丸いアイコンを乗せた例は40枚中0枚。

使ってよいのは3つの場合だけ。

1. **線画のまま、器に入れずに置く**（コスモの6資本）
2. **番号や分類を担うバッジにする**（セーフィーの①〜⑥、GAのAIバッジ）
3. **その丸が「工程の1点」「収斂点」を意味するとき**だけ器に入れる

作るときの作法。線幅＝外形÷14、本文の縦棒の2.5〜3倍。端も角も丸。1つのアイコンに使う色は1色。
器に入れるならアイコンは円の55%。

**アイコンを選ぶときは、その概念そのものを描く。**
「調査と報告」に時計を当てるのは、時間の話をしていないなら誤り。
持ち物1個で機能を言う。新しい絵を描かず、既存の絵を2つ重ねる（円＋斜めの柄＝虫めがね、虫めがね＋折れ線＝分析）。

## 作る前のチェック

図を書き始める前に、次に答えられるか確かめる。答えられないなら、まだ図にできない。

1. この図の**起点**は何か。左端（または下端）に何を置くか
2. **運動**は何か。左→右か、上から下か、円環か。それを何で表すか（矢羽／面の傾き／幅の変化／濃淡の順序）
3. **終点**は何か。それをどう形で区別するか
4. 箱の中を**2層に割る**なら、見出し行と説明行に何を書くか
5. **数値**を1つ入れられるか。年・件数・比率・工数のどれか
6. 図の外に出す**軸の名前・凡例・注記・締めの一文**は何か
7. 長方形のままでよいか。**意味のある形**に置き換えられないか

## 作ったあとのチェック

- 要素数は40以上あるか（中央値47）
- 図の中の文字数は250字以上あるか（中央値375字）
- 入れ子は3層あるか（面→箱→箱の中の階層）
- 1行の中で太さ・色・大きさを2つ以上変えている行があるか
- 起点・運動・終点が全部あるか
- 装飾だけのアイコンが残っていないか
- 図領域に地が敷かれているか
- フッター（ロゴ・コピーライト・ページ番号）があるか

## 構造を示す図を選ぶ ── 母数から

実企業スライド1,684枚を全数走査したところ、構造図（支える／支えられるの関係を示す図）は**47枚**しかない。
型を選ぶ前に、母数の分布を見る。

| 型 | 枚数 | 割合 |
|---|---|---|
| ピラミッド | 24 | 51% |
| 屋根なしの柱列＋下支え帯 | 9 | 19% |
| 比喩（木・氷山・灯台） | 5 | 11% |
| 神殿・家型 | 5 | 11% |
| 帯の積み上げ | 4 | 9% |

**屋根・柱・土台の3点セットを揃えた図は4枚（8.5%）しかない。** 神殿型は少数派で、しかも次の制約がある。

- **柱を長方形のまま4本並べると「4分割された1本の帯」に見える。** 柱の面積が並びの88%を占めるため。
  長方形のままの11枚はすべて3列以下か横帯だった
- 4本で柱に見せている唯一の例は軸を柱頭の0.37まで絞っている（軸÷柱頭が0.9では寸胴になる）
- 柱の本数は3本が57%
- **屋根の台形は0枚。** 帯・パネル9／ピラミッドの尖り23／三角2／五角形2／山型1
- 屋根の高さ÷幅の中央値は0.111
- 幅を段ごとに変えるかは半々。実測4枚のうち2枚は全層等幅。**1社から一般化してはいけない**
- 柱頭・柱脚を付けているのは3枚（21%）
- 土台2段以上は25%。上ほど濃いが58%
- **影・グラデーション・立体は74%が不使用。屋根と柱で構造を語る図に立体を使った例は1,684枚に1枚もない**

**4つ以上を並べるなら、神殿型ではなく柱列＋下支え帯を使う。**

### 柱列＋下支え帯の作り（母数9枚。最も密度が高いのは HAKUTEN `img/39/11`）

列を1本ずつ、上から次の順で積む。

1. **見出し帯** ── 黒か濃色のベタ、白抜き、列幅にぴったり。「戦略アジェンダ I」のような通し名
2. **大見出し** ── 列の識別色、太字、本文の1.5倍。「提供価値の強化」
3. **副題** ── 黒、太字、小。「再現性ある収益モデルの確立」
4. **説明** ── グレー、細字、2〜3行
5. **番号つきピル** ── 3〜4個。枠だけ（塗らない）、枠の色は列の識別色、番号は色付き太字、本文は黒。**番号は列をまたいで通しで振る**（01〜04、05〜08、09〜11）
6. **指標のタグ** ── グレーの小さい角丸タグ＋その右に本文1行
7. **矢羽の列** ── 4枚。最後の1枚だけ識別色のベタ＋白抜き

下段に**灰色の帯を1〜2本**、列の並びと同じ幅で敷く。帯の左に大きめの見出し、右に番号タグつきの白い小箱を並べる。

列ごとに識別色を1つ割り当てる（赤・緑・紫のように色相で分ける）。見出し帯は黒で共通、土台は灰で共通。

**列を4本にするときは、列の中身を減らす。** 1列の幅は版面幅12.13inを4等分して約2.85in。
11ptで1行あたり18文字しか入らないので、番号つきピルは次のページへ送る。

## 図の部品を、型として持つ

毎回ゼロから図を組むと、ページごとに作りがばらつく。**17種の型を持ち、内容から型を選ぶ。**

| 型 | 形 | 選ぶ場面 |
|---|---|---|
| 章扉 | 左に目次再掲、右に章番号と章名 | 章の切り替え |
| 現在地 | 右上に小さい帯を横に並べ、現在地だけ濃く | 同じ主題が複数ページ続くとき |
| 締めの帯 | 全ページ同じ高さの横帯 | 全ページ |
| 表 | 行＝論点、列＝観点。1列に地を敷いて主役にする | 最頻。3〜4列まで |
| カード | 項目名の帯＋1行の説明 | 並列で、順序に意味がないとき |
| 特大の数字 | 数字4枚。1枚だけ色を変える | 規模・件数を先に見せるとき |
| ガント | 行＝主体、横軸＝工程。バーの中に成果物名 | 誰がどの区間を担うか |
| 二層 | 上下2段に分け、間に境界の一言 | 「この線から下は別の層」 |
| 工程帯 | 2レーンを並べ、区間の幅で期間の比 | 前後の比較 |
| 特大＋横棒 | 左に特大の数字、右に内訳の横棒 | 1つの数字と、その内訳 |
| 開き | 2本の曲線と、間を塗った面 | 差が開いていく関係（模式図） |
| 左右2列 | 見出しの帯を2つ並べ、下に対の行 | AとBの対比 |
| 行頭ラベル | 左にラベル、右に本文 | 箇条書きを図に見せる |
| 縦横の表 | 列＝選択肢、行＝比べる項目 | 選択肢の比較 |
| 矢羽 | 段階を左から右へ。境目を破線で | 段階の進行 |
| 時系列 | 上に線と点、下に各段のカード | 手順・経過 |
| 様式 | 記録の名前と、その列を並べる | 巻末の様式一覧 |

**1ページに図は1つ。** ブロックが3つ以上になったらページを割る。
2つまでなら、上のブロックを上詰めにして積む。

## 数字を主役にするとき

特大の数字は、**数字と単位を別の枠に置く。** 同じ枠に入れると、単位の級数で
枠の高さを見積もれず、はみ出すか折り返す。

```
数字の幅 ≒ 桁数 × 0.55 × 級数 / 72   （欧文の字幅は全角の0.55）
単位は その右に、数字の下端に合わせて配置する
```

4枚並べるなら、**1枚だけ色と地を変える。** 全部同じ色だと、どれを見ればよいかが伝わらない。
変えるのは「この資料で一番言いたい数字」の1枚だけ。
