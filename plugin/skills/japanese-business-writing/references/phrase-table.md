# 置換表（全量）

実案件で指摘を受けた表現を、直し方ごとにまとめている。資料を書き終えたら通す。
案件ごとに行を足していく。追加した語は `scripts/patterns.json` にも反映しておくと、機械走査で拾えるようになる。

|---|---|
| 移行対象の選定を実施いただく | どこまで移すか決めていただく |
| 変換作業の実施が必要となります | 一件ずつ置き換える作業が要ります |
| ご確認をお願いいたします | ご確認ください |

| 何を移すかが見えてから詰める部分です | 何を残すかが決まってから詰めます |
| ご確認いただきたいところです | ご確認ください |
| 順次対応していく形になります | 順次進めます |
| 費用に影響する点になります | 費用が変わります |

## 5. 口語を対外資料の語へ

| 口語寄り | 対外資料 |
|---|---|
| マニュアルには載っていません | マニュアルには記載されていません |
| 現行にはありません | 現行には存在しない機能です |
| 資料名と項番を書いています | 対応する資料名と項番を記載しています |
| 実現はできますが | 実現可能ですが |
| 番号がありませんでした | 番号が付与されていませんでした |
| 同資料にも入れたうえで | 同資料にも反映したうえで |
| ご説明いたします | ご展開いたします |
| 申し送り | 申し送り事項 |
| いったん振った項番は動かしません | 採番済みの項番は変更しません |
| 項目を足すときは末尾に振り、削るときは欠番のまま残します | 項目の追加は末尾に振り、削除は欠番とします |
| ずれないようにします | 齟齬を防ぎます |
| 設けません | 実装しません |
| ときだけ | 場合のみ |
| 〜となっています | 〜です |
| 使いました | 使用しています |

例外：区分の名称のように相手が繰り返し目にする短い語は、平易なほうを選ぶ（「現行同等」ではなく「現行どおり」）。

| AI的 | 自然 |

## 9. 約束の強さ

| 断定してよい（自社の意思） | 断定してはいけない（技術的な結果） |
|---|---|
| 移行ツールはこちらで作ります | 今までと同じURLで開ける状態を保ちます |
| 8月中旬までに計画書へ反映します | 記事を移すのとほとんど同じ手間がかかります |
| 確認は全件を目視する想定です | 対象年が決まると、件数も工数も固まります |

書き換え例。

- 「今までと同じURLで開ける状態を保ちます」→「今までと同じURLで開ける状態を**できるだけ**保ちます」
- 「ほとんど同じ手間がかかります」→「同じ程度の工数がかかる**おそれがあります**」
- 「対象年が決まると、件数も工数も固まります」→「対象年が決まることで、件数や工数の算出が**行えるようになります**」

## 14. 技術語を読み手の語彙へ

相手が非技術者のときだけ使う。business の側は正確に、technical の側だけ噛み砕く。

| 技術語 | 一般向け |
|---|---|
| データ移行 | 今のページを新しいサイトへ移す |
| スキーマ変換 | データのしまい方を合わせる |
| 静的ページとして保持 | 今のページをそのまま残す |
| 権限制御 | ログインした方だけが見られるようにする |
| 工数 | 作業にかかる日数／人手 |
