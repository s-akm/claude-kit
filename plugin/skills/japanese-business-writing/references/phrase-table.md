# 置換表（全量）

これまでのプロジェクトで指摘を受けた表現を、直し方ごとにまとめている。資料を書き終えたら通す。
プロジェクトごとに行を足していく。追加した語は `scripts/patterns.json` にも反映しておくと、機械走査で拾えるようになる。

## 9. 約束の強さ

| 断定してよい（自社の意思） | 断定してはいけない（技術的な結果） |
|---|---|
| 移行ツールはこちらで作ります | 今までと同じURLで開ける状態を保ちます |
| 8月中旬までに計画書へ反映します | 記事を移すのとほとんど同じ手間がかかります |
| 確認は全件を目視する想定です | 対象年が決まると、件数も工数も固まります |

書き換え例。

- 「今までと同じURLで開ける状態を保ちます」→「今までと同じURLで開ける状態を**できるだけ**保ちます」
- 「ほとんど同じ手間がかかります」→「同じ程度の工数がかかる**おそれがあります**」
- 「対象年が決まると、件数も工数も固まります」→「対象年が決まることで、件数や工数の算出が**行えるようになります**」

## 27. 変更点の報告（箇条書き）

| 和語の述語・部品名 | 置き換え |
|---|---|
| 〜にした | 〜に修正 |
| 注記を足した | 注記を追加 |
| 未確定を外した | 未確定を削除 |
| 〜に変え、未確定を付けた | 〜に未確定として修正 |
| 最後の箱を「〜」に変えた | 「〜」に修正 |
| 「〇〇を入力し、」を足した | 〇〇の入力操作を追加 |
| アプリから PC へ付与する | アプリから PC へ付与リクエストを行う |
