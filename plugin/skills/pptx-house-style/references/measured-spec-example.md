# 実測値の書き出し方（記入例）

`pptx_measure.py` の出力をそのまま貼らず、この形の表に落としてからユーザーへ提示する。
納品時にもこの表を添える。次に誰かがスライドを足すとき、この表を渡せば同じ体裁で作れる。

以下は実案件（16:9、コーポレートカラーが紺のテンプレート）の記入例である。
**数値をそのまま流用しない。** 対象デッキで測り直した値に置き換える。

## この資料で踏んだ注意点

- テキスト枠は tIns/lIns/rIns/bIns を 0、自動調整なし（`noAutofit`）で統一する。混在すると同じ top を指定しても文字位置がずれる。
- 罫線は `add_connector` を使わず生XMLで引く。既定スタイルの影が乗って太く濁って見える。
- 角丸は表紙の装飾のみ。本編は直角で統一する。
- 丸付き数字は段落先頭に使わない。
- 英字の略称は半角。案の記号のみ全角（Ａ案・Ｂ案）。
- 区分列は 0.70in では「変更あり ※」が改行するため 1.05in にした。
