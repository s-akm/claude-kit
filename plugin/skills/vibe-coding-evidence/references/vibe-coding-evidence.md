## 2. 生成コードの品質・セキュリティ

| 数値 | 内容 | 出典 |
|---|---|---|
| 45% | 生成コードのうち既知の脆弱性を含んでいた割合。セキュリティ合格率は約55%で2年間横ばい | Veracode「Spring 2026 GenAI Code Security Update」2026年3月 |
| 95%超 | 構文としては正しい割合。つまり「動くが危ない」 | 同上 |
| 82% / 86% | SQLインジェクション／暗号化アルゴリズムで基準を満たした割合 | 同上 |

**画面まわりと記録まわりが落ちる**、という切り口は経営層に伝わりやすい。
「画面を操作している限り気づけない欠陥」と言い換える。
